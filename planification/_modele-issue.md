# Modèle d'issue

Copier ce canevas pour une issue nouvelle **uniquement** si l'exigence existe déjà dans le cahier des charges.

```markdown
## ISS-nnn — Titre à l'infinitif, vocabulaire métier français

| Champ | Valeur |
| --- | --- |
| Statut | À faire |
| Lot | Lx |
| Priorité | Must / Should / Could |
| Réf. | EF-nn, RG-nn, ENF-nn |

**Objectif :** une phrase.

**Acceptation**
- [ ] critère observable
- [ ] test automatisé (TDD)

**Hors périmètre :** ce que cette issue ne fait pas (volumes, IoT, opérateur réel, etc.).
```

Identifiants : continuer après ISS-068. Ne pas réutiliser un numéro.
